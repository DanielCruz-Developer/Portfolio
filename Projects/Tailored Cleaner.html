Highlights

Lean, careful and yours.

Stops before it spends

The match agent scores the job against your CV first. Below 0.65 the run pauses and asks, so no tokens go into drafts for a weak fit.

0.78gate 0.65

A check loop that only shrinks

A judge reviews both documents and returns exact fixes. The first pass freezes the list of problems; later passes only re-check it, so the loop always converges.

pass 1 · 7 fixespass 2 · approved345

Your layout, kept

The CV reader captures your CV's structure as a template, so the edited version lands back in your own sections and order instead of a generic format.

Models that fail over

Every agent has its own OpenRouter model chain, picked for its job. Reasoning models plan, faster models write, and a failing model hands over without stopping the run.
