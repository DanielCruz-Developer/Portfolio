Desktop Manager

Dock your laptop and Windows scatters your desktop icons. Undock it and it happens again. Desktop Manager remembers a layout for every display setup and puts each icon back on the right monitor, in the right spot, the moment your screens change.

How it works

Plugging in, unplugging, sleep and wake: every display change runs the same five steps.

  1. Detect

    A display change fires. The app waits 2.5 s for Windows to finish settling before it trusts anything.

  2. Snapshot

    The last-known-good layout is written to the old profile, so nothing is lost even if Windows already scrambled things.

  3. Pause autosave

    Autosave stops, so a scrambled desktop can never overwrite a good layout.

  4. Match

    Same monitors, by serial? Restore silently. Anything else asks first, and suggests a layout from a setup with the same number of displays.

  5. Restore

    Every icon returns to its monitor and spot. Borrowed layouts are mapped left to right and scaled; anything that won't fit takes the nearest free slot.

        Features

        Restoring icons was the start.

        It grew into a small desktop toolkit: an editor, desktop objects, and PowerToys-style utilities.

        A profile for every setup

        A profile is a set of displays, identified by serial, with its own icon layout. Two monitors of the same model are still told apart.

        Autosave, with history

        Saves as you work, keeps the last 10 versions of every profile, lets you pin the good ones, and can undo an automatic restore in one click.

        10 versionspinned · in use

        Visual layout editor

        Rearrange a setup without plugging it in. Drafts with undo, zoom per display, snap to the grid (hold Alt for free placement), and drag icons between monitors.

        8 desktop widgets

        Zones, group folders, pictures, notes, clock, weather, reminders and alarms. A no-overlap rule means none of them can ever hide an icon.

        Built-in utilities

        On-demand tools with their own customizable shortcuts. Layout actions never get one, so you can't restore by accident.

        Win+Ctrl+TAlways on Top
        Win+Shift+TText Extractor

        Import between displays

        Copy any display's layout onto another, from any profile. Positions scale to the new resolution, and anything in the way slides to the nearest free spot.

        Safe by design

        Export and import, plus a silent backup every 14 days (the last 4 are kept). The app never deletes a file; deleted profiles are archived first.

        Native, in three languages

        Lives in the tray, starts with Windows, follows light and dark mode, and speaks English, Spanish and French, matching your Windows language by default.

        Under the hood

        The hard parts weren't the UI.

        The Windows desktop has quirks you only find by measuring. These findings shaped the design.

        Desktop layering

        One window draws every icon

        All desktop icons on a monitor are painted by a single Explorer list view, so nothing can be slotted between them. Everything the app draws sits above that layer, and a no-overlap rule makes objects reserve space the way icons do.

        Nothing goes underneath, so the wallpaper layer (including Wallpaper Engine) is never touched.

        Coordinate space

        A grid that fits every screen

        Windows spaces icons at a fixed pitch, so most resolutions end with a strip it can't use and the spacing shifts with scaling. Desktop Manager divides each monitor into equal cells that fill it edge to edge, so icons line up evenly and a layout moved to another resolution lands in the matching cell.

        Monitor identity

        Monitors are fingerprinted from EDID

        Each monitor is identified by manufacturer, product code and serial, read from the EDID data Windows caches in the registry. Panels without a serial, usually laptop screens, fall back to the device instance path, which is still unique per connection.

        Testing

        A pure, tested core

        All the geometry lives in a UI-free core library: snapping, group moves, collision resolution, moves between monitors and proportional grids. The WPF app just draws what the core decides.
